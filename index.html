🌐 纯网页实现，无需任何App

Siren是100%的网页应用，所有功能都在浏览器中运行：

  • ✅ 无需下载：直接在浏览器中打开网址即可使用
  • ✅ 无需安装：不需要安装任何应用程序或插件
  • ✅ 跨平台：电脑、手机、平板都能用同一个网址访问
  • ✅ 即时更新：刷新页面即可获得最新功能
  • ✅ 隐私安全：所有AI运算在您的设备上进行，数据不上传

💻📱 如何访问

方法1：本地测试（开发阶段）

  1. 下载代码到本地
  2. 在命令行运行：python -m http.server 8000
  3. 电脑访问：浏览器打开 http://localhost:8000/index.html
  4. 手机访问：
    • 确保手机和电脑在同一WiFi
    • 找到电脑的IP地址（如 192.168.1.100）
    • 手机浏览器打开 http://192.168.1.100:8000/index.html

方法2：GitHub Pages部署（推荐）

  1. 代码已推送到GitHub仓库
  2. 在仓库设置中启用GitHub Pages
  3. 所有设备访问同一个网址：
    https://yzhu24-ship-it.github.io/siren/
  4. 电脑、手机、平板用同一个链接，自动适配
⚠️ 浏览器要求
电脑端：
• Chrome 90+ / Edge 90+ / Firefox 88+
• Safari 14+ (Mac)

手机端：
• Chrome 90+ (Android)
• Safari 14+ (iOS)
• 需要摄像头权限（AR版本）
• 建议使用HTTPS（GitHub Pages自动提供）
