# Life Choices Game

An interactive 3D narrative game where you make life-changing decisions through a series of choices and mini-games.

## How to Play

### Option 1: Direct Download (Easiest)

1. Download the `index.html` file from this repository
2. Double-click the file to open it in your web browser
3. That's it! The game will start automatically

### Option 2: Clone and Run

```bash
git clone https://github.com/yzhu24-ship-it/siren.git
cd siren
git checkout claude/life-choices-game-design-011CUsj42hK9hBmqLicStAwc
```

Then open `index.html` in your browser.

### Option 3: GitHub Pages

If this repository has GitHub Pages enabled, you can play directly at:
`https://yzhu24-ship-it.github.io/siren/`

## Game Controls

- **WASD** or **Arrow Keys** - Move your character
- **Walk into doors** - Make your life choices
- **Mouse** - Interact with mini-games

## Game Features

- **3D Environment**: Gray abstract room with ragdoll-style character
- **4 Mini-Games**:
  - Sudoku Puzzle
  - Geography Quiz
  - Code Debugging Challenge
  - Hurdles Race
- **8 Different Endings**: Based on your choices and performance

## Game Paths

### Path 1: Study
- Complete Sudoku puzzle
- Choose Arts or Science
  - Arts → Geography quiz
  - Science → Debug code

### Path 2: Sports
- Complete hurdles race
- Outcomes based on performance
  - Perfect run → Continue as athlete or become coach
  - Hit hurdles → Keep trying or switch to studying
